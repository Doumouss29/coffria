# Coffria v1.4.3

Correctif du menu Actions et ajout de la modification du partage des dossiers.

- Les commandes du menu sont déclenchées dès `pointerdown` avant sa fermeture.
- Prévisualisation et téléchargement ouvrent immédiatement un nouvel onglet afin d'éviter le blocage des fenêtres par le navigateur.
- Ajout de l'action « Modifier le partage » pour les dossiers.
- Ajout des routes API de lecture et de mise à jour des accès d'un dossier.
- Les niveaux disponibles restent : toute l'entreprise, moi seul, personnes ou groupes spécifiques.
